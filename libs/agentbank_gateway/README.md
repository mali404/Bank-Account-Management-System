# agentbank_gateway

Agent gateway: defense plugin host and taint-tracking interfaces (SPEC §5.4, §9, §19). D0 baseline in M0. **M4** runs the six LangGraph agents through this gateway; defenses D1–D10 are **M6**. The reference-model benign utility is 1.0 (`runner.BENIGN_UTILITY`).

Part of the [AgentBank-Sec Testbed](../../README.md). Apache-2.0.
